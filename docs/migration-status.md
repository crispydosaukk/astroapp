## Known deviations (deliberate, documented)

1. **AI Chat back** — source calls `context.go('/home')`, an undeclared route (GoRouter error page). RN goes to the Home tab.
2. **Remedies wheel taps** — in Flutter the spoke `CustomPaint` is the last Stack child and absorbs hit-tests, so the
   8 wheel nodes cannot actually be tapped despite "Tap any direction". RN makes the spokes `pointerEvents="none"`.
3. **Push transition** — native-stack `slide_from_right` (300 ms on iOS; Android uses the platform duration) instead of
   GoRouter's simultaneous slide+fade. Onboarding/birth-profile use `fade` without the 4 % slide.
4. **AnimatedSwitcher** — new child slides/fades in; the outgoing child is removed immediately (no cross-fade overlap).
5. **Splash particles** — Dart `Random(42)` cannot be reproduced in JS; a seeded PRNG gives a stable but different layout.
   The sweep gradient is approximated with 10 arc segments.
6. **BackdropFilter blur** — implemented with `expo-blur` where content sits behind (bottom nav, filter sheet, sticky CTAs);
   omitted on cards drawn over flat backgrounds, where the blur has no visible effect.
7. **RemedyDetail without payload** — Flutter required the payload; RN shows an empty state if opened directly (deep link).
8. **Search field "Clear Filters"** (Live Astrologers) — preserved Flutter quirk: the query resets but the uncontrolled field keeps its text.
9. **Reselecting the active tab** — branches hold one route each, so `goBranch(initialLocation: true)` was a no-op; RN emits `tabPress` only.
